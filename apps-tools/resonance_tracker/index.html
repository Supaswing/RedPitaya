Start and stop are baseline-scan frequencies, independent of the single-frequency Raw I/Q control. Filter radius is the half-width of the centered quadratic smoothing window (total width = 2r+1); overview points must be at least 2r+5. Coarse candidates are accepted only for 50 ≤ Q ≤ 150. A refined model quality below 0.20 triggers the next candidate, up to three attempts per resonance. Changes are sent to the backend immediately and are fixed for the duration of a baseline run. The displayed window estimate excludes conditional retry measurements. Current configuration requires approximately 371 coherent measurement windows.
